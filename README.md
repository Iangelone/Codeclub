# Codeclub

Open source desktop IDE for artificial intelligence, made in Argentina.

## Product direction

Codeclub helps create applications with AI and turns each project into an observable product workspace. The agent can inspect and modify a project, organize plans and TODOs, measure AI usage, and expose project evidence that can support diagnosis and commercialization.

The current loop is:

1. Build an application with the agent.
2. Keep plans, TODOs and execution artifacts associated with the project.
3. Measure generations, tokens, duration and estimated model cost locally.
4. Use the evidence to diagnose progress, scope and delivered work.
5. Turn that diagnosis into a proposal, pilot or sales conversation.

See [the product workflow](docs/product-workflow.md) for current boundaries and next steps.
