# About Codeclub

Codeclub is a small, opinionated desktop workspace for people who build software with AI.

It started from a simple observation: an AI coding session is rarely just a chat. Real work moves between files, terminals, browser tabs, project decisions, checks, and the occasional “what exactly changed here?”. Codeclub brings those pieces closer together so the work has a place to happen and a trail that is easy to follow.

## What we are trying to build

Codeclub aims to make agent-assisted development feel calm, local, and understandable. The agent should be capable of doing useful work, while the interface keeps the person aware of the project, the tools being used, and the evidence left behind.

That means a few practical values:

- Local by default: projects and working history stay close to the machine.
- Human in the loop: sensitive actions should be visible and confirmable.
- Evidence over theater: plans, TODOs, logs, and artifacts are more useful than grand claims.
- One workspace: chat, code, terminal, browser, and review should cooperate without pretending they are the same thing.
- Room to grow: integrations and future device connections can be added without making the core workflow noisy.

## What Codeclub is not

It is not trying to replace a full IDE, a project-management suite, or a hosted AI platform overnight. It is a focused desktop companion getting better one workflow at a time.

Some ideas are intentionally still visible as ideas. Devices, Synapse, richer release traceability, and fully automatic scheduled runs need more runtime work before they become dependable features.

## Who it is for

Codeclub is for independent developers, small teams, students, and curious builders who want to experiment with AI coding tools while keeping their local workspace and decisions close at hand.

## A humble status note

The project is in early beta. Rough edges are expected, and feedback is part of the design process. If a workflow feels unclear, too magical, or unnecessarily heavy, that is useful information.
